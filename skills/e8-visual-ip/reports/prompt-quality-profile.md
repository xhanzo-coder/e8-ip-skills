# Prompt 质量画像

## 任务建模

- Role：角色设计与一致性审计，不是照片滤镜器。
- Task：在稳定人物身份上执行指定风格的结构重绘，并完成可追溯 QA。
- Format：基础规则＋身份锚点＋相似程度＋风格定义＋配色＋交付类型＋参考用途＋不可变项＋禁止项。

## 质量标准

1. 完整：身份、风格、任务、参考图角色和禁止项齐全。
2. 清晰：不能只写“可爱Q版”“像参考图”这类不可检验表述。
3. 一致：`plan.md`、Prompt 与实际图片工具输入必须使用同一组参考。
4. 实用：每条要求能在候选图中观察，或能在运行契约中校验。
5. 具体：优先使用选中风格定义中的比例、线条、形状、媒介和背景硬门。
6. 身份可检验：`recognizable/close` 必须写五项头部几何指纹，不能只写发型、服装和配饰。
7. 单次可控：一次生成授权只组装一张候选 Prompt；失败后的额外校准或第二版需要新的明确授权。
