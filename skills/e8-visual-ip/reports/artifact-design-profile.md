# 交付物设计画像

本 Skill 的核心交付是视觉证据，不是长篇说明。用户首先应看到可比较的候选图，其次看到简洁、可操作的差异判断。

## 呈现方向

- 基础人物：同画幅、完整全身、中性背景，候选之间只保留有意义的结构差异。
- 风格确认：候选与主风格参考并排；明确说明“保留了什么身份”“迁移了什么风格语法”“禁止复制了什么”。
- 三视图：正、侧、背等高、同基线、同一比例与配色；正面未确认前不制作完整三联图。
- 修复：显示目标图、问题点和修复结果；不得把未修复项藏在文字里。
- QA：先给 PASS/FAIL，再给最关键的 1—3 个理由；失败图不作为推荐候选展示。

## 反模式

禁止用海报装饰、渐变背景或精修光效掩盖人物结构；禁止只展示一张漂亮图却没有参考对照；禁止把 Prompt、文件树或内部参数当成用户主要交付。
