# Library 就绪说明

## 已验证

- dev、holdout、blind holdout、adversarial 四组触发评测均无误触发与漏触发。
- 风格注册表包含软萌潮玩与像素角色两个正式内置风格，以及黑灰墨线一个隐藏候选风格。
- 注册表、定义、引用、哈希与来源清单一致；不再包含已删除的极简黑白漫画风格。
- 角色包生命周期、软萌潮玩契约、像素运行契约、黑灰墨线候选契约与 UTF-8 包完整性测试通过。
- Trust 检查通过：4 个 CLI 均有帮助入口；无网络脚本、无密钥发现；唯一文件写入能力限定在角色包边界内。
- 输出契约为 7 个案例，其中 2 个是 `file-backed fixture`；with-skill 断言通过率 100%，baseline 为 0%。

## 仍为 missing evidence

- 不同模型上的真实生图 A/B。
- 未见人物身份上的盲审相似度和风格还原度。
- 复杂场景、多人及像素复杂动作等注册表中的 `unverified_outputs`。
- 黑灰墨线仍是隐藏候选，不进入首次风格目录，也不能宣称已具备稳定批量产物。

## 发布边界

当前可作为中央 Library Skill 在链接项目中使用和继续测试。所有已登记参考资产均按 `assets/provenance.json` 的权属记录公开分发；新增资产必须先登记来源、哈希与授权状态。
