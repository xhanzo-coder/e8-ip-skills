# Retest prompts

这些提示词用于新环境中的真实前向测试，不包含预期答案。

1. `我第一次使用这个 Skill。这里有三张我的照片，请帮我创建个人视觉 IP。`
2. `根据这张正装照创建个人 IP，但不要直接把西装和白背景当成人设。`
3. `我明确想要像素角色设定风，先给我人物方案，不要立即生成。`
4. `我不知道选什么风格，请展示现有风格，并告诉我哪个更适合做表情和文章配图。`
5. `这张候选还行，先存起来以后再改。`
6. `给已经确认的人物增加这张新风格参考，确认后再做一组动作。`
7. `比较这四张图，检查是不是同一个人物，分别指出身份漂移和风格漂移。`
8. `使用已确认人物做一个挥手动作，只改动作，不要改变脸、发型和服装。`
