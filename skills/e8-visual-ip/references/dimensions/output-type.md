# 交付类型

| 类型 | 目标 | 关键约束 |
|---|---|---|
| `base-character` | 正式基础人物 | 完整全身、无场景无文字、最终确认后保存角色包 |
| `style-variant` | 同一人物的新风格母图 | 保持身份连续和可比画幅；按风格策略决定只换媒介或连形状语法一起重绘 |
| `turnaround` | 正面、侧面、背面 | 比例、服装结构和锚点方向一致 |
| `avatar` | 方形或圆形安全区头像 | 缩小可识别，裁切不破坏发型和符号 |
| `expression` | 单个或一组情绪 | 固定头型、脸龄和五官语法，只改变情绪 |
| `pose` | 动作与姿势 | 固定人物比例，检查手脚和道具关系 |
| `sticker` | 透明贴纸或表情包 | 轮廓清楚、背景透明、缩小可读 |
| `outfit` | 换装 | 保持脸、发型、比例、招牌符号和强调色载体 |
| `scene` | 应用场景 | 人物身份不被环境色和透视改写 |
| `consistency-audit` | 比较多张图片 | 输出人物漂移、风格漂移和任务问题 |
| `repair` | 修复一张图片 | 只修指定问题，重复全部不可变项 |

基础人物未确认时，只能继续人物候选和修改，不能生成正式衍生资产。新风格未确认时，不得用它批量生成正式产物。
