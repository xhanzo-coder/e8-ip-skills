# 相似程度

相似程度控制照片对角色身份的影响，不等同于写实程度。

| 值 | 含义 | 参考图策略 |
|---|---|---|
| `close` | 较强本人辨识度，但仍是明确 Q 版角色 | 可使用一张清晰本人照片作为身份参考，禁止复制姿势和真人比例 |
| `recognizable` | 能认出本人，角色感优先 | 默认；照片提供筛选后的发型、眉眼气质和招牌特征 |
| `interpreted` | 只保留关键气质和符号 | 优先使用文字化身份特征，避免照片结构锁死 |
| `symbolic` | 用象征角色表达本人 | 照片只提供灵感，不要求真人脸部相似 |

## 自动推荐

- 用户说“要像我、别人能认出” → `recognizable`，明确要求更像时才用 `close`。
- 用户说“抽象一点、角色感强” → `interpreted`。
- 用户说“吉祥物、符号角色、不要人脸” → `symbolic`。
- 用户不确定 → `recognizable`。

## 误区

- “更像我”不等于增加写实五官、拉长身体或复制照片。
- “抽象”不等于增加几何背景；必须改变人物结构或特征提炼方式。
- 单张照片中的姿势、背景和当天穿搭不属于相似度锚点。

## `recognizable` 验收

`recognizable` 不是“发型和衣服像”。至少需要在目标风格允许的抽象程度内保留脸部比例、发际线额头、眼眉关系、中下脸关系和年龄神态。若只能依靠发色、眼镜、领带、卫衣或道具猜出人物，应判为身份失败。

某个风格的固定脸部语法与人物身份冲突时，必须让身份控制具体五官几何，让风格控制媒介与抽象方式；不能为了风格一致把所有人压成同一张脸。
