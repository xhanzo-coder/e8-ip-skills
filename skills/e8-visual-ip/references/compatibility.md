# 组合兼容性

## 当前内置风格

| 人物方向 | 软萌潮玩Q版 | 像素角色设定风 | 说明 |
|---|:---:|:---:|---|
| `recognizable-chibi` | ✓✓ | ✓ | 像素概括会降低细微面部相似度，需优先保留稳定身份锚点 |
| `graphic-chibi` | ✓✓ | ✓✓ | 像素簇、有限色板和清楚剪影适合图形化角色 |
| `symbolic-mascot` | ✓ | ✓ | 可用，但需重新确认符号化后仍保留哪些身份锚点 |

## 交付兼容

| 交付类型 | 软萌潮玩Q版 | 像素角色设定风 |
|---|:---:|:---:|
| 正式人物 | ✓✓ | ✓✓ |
| 头像 | ✓✓ | ✓✓ |
| 三视图 | ✓✓ | ✓✓ |
| 表情 | ✓✓ | △ |
| 动作 | ✓✓ | △ |
| 小尺寸贴纸 | ✓✓ | △ |
| 大幅周边 | ✓✓ | △ |
| 复杂场景 | ✓ | △ |

`✓✓` 为优先推荐，`✓` 为可用但需要额外 QA，`△` 为当前参考与测试尚未充分覆盖。像素风已支持基础人物、头像和三视图；表情、动作、贴纸、换装与场景仍需逐项验证，不能批量承诺。

## 后续自定义风格

新风格确认前必须单独建立兼容判断，至少说明适用人物方向、交付类型、身份保持方式、媒介冲突和专属 QA。不得沿用已删除风格的兼容结论，也不得默认与所有产物兼容。

## 冲突处理

- 用户要求符号型角色同时保持高度真人脸部相似：建议改为图形型或辨识型 Q 版。
- 用户要求变化稳定身份锚点、脸龄气质、招牌系统或人物方向：识别为人物重设计。
- 当前风格声明 `structural-redraw` 时，允许重新解释具体脸型、眼睛画法、发丝边缘、身体曲线和姿势节奏；这些变化本身不等于人物重设计。
- 用户要求当前未内置风格时：进入自定义风格候选流程，不用现有风格近似冒充，也不调用已删除风格。
- 用户选择像素风格但要求平滑曲线、抗锯齿、渐变和照片级色彩：说明媒介冲突；必须选择原生像素网格或另建非像素风格。
