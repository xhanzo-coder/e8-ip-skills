# 软萌潮玩 Q 版

## 目标

把真实人物重新设计成二维生活潮玩角色，而不是把本人美化成精致动漫立绘。结果必须同时成立：像本人、属于四张参考图的共同风格、具备可继续制作侧面和背面的清楚角色结构。

优先级固定为：

```text
目标风格的比例与形状语法
→ 本人的稳定身份锚点
→ 长期角色服装与招牌符号
→ 漂亮和精致程度
```

“更像本人”不得通过真人比例、成熟脸、写实长发、时尚腰身、精细妆容或照片穿搭复刻来实现。

## 参考图库

四张图属于同一个宽泛风格家族，但存在明显的五官与角色密度差异。首次目录只展示 `minimal-face`，用户据此选择后也默认使用 `minimal-face` 作为主参考；不得自动把目录选择切换成另一张参考。其他参考只能作为明确展示差异后的替代路线。

| 内部路由 | 参考图 | 主参考适用信号 | 只学习 |
|---|---|---|---|
| `minimal-face` | `reference_assets.minimal_face` | 本人五官适合高度简化，或目标更紧凑、更符号化 | 读取 `prompt_profiles.minimal_face`；使用豆点眼、胶囊脸、2.7～3头身、暖色粗线和圆润衣物 |
| `expressive-eye` | `reference_assets.expressive_eye` | 眉眼和眼神确实是本人重要身份锚点 | 有限层次大眼、轻微情绪、稍轻盈但仍玩偶化的比例 |
| `accessory-led` | `reference_assets.accessory_led` | 眼镜、发型或长期配饰承担较强识别 | 极简五官、高识别配饰、分层穿搭、生活角色设计 |
| `round-open-eye` | `reference_assets.round_open_eye` | 基础人物需要清楚睁眼，但不适合精细动漫大眼 | 圆形睁眼、白眼球、单色虹膜、极少高光和稳定正侧背眼型 |

内部路线不能静默替换目录画法。不得因为本人是女性、长发或五官漂亮，就自动选择 `expressive-eye`。Skill 可以在身份分析后建议 `expressive-eye`、`accessory-led` 或 `round-open-eye`，但必须先展示与 `minimal-face` 的画法差异并获得用户同意。

选择 `minimal-face` 时，必须完整读取 [Minimal Face Prompt Profile](soft-toy-profiles/minimal-face.md)。Profile 的比例、五官、线条、渲染、三视图和专属 QA 覆盖本文件中的宽泛规则；通用 Prompt 不得替代 Profile，也不得把 Profile 压缩成“可爱Q版＋粗线＋平涂”。

### 参考输入硬要求

每次创建本风格人物，`plan.md` 必须记录：

- 全部身份参考图的实际路径与 `identity` 角色。
- 主风格参考图的实际路径、内部路由和 `primary style` 角色。
- 可选辅助参考图的实际路径、补充目标和 `secondary style` 角色。
- 本次明确禁止从参考人物迁移的服装、帽子、眼镜、文字、道具、配色和性别表达。

调用支持多参考图的图片工具时，必须把身份参考、主风格参考和已选辅助参考真实传入调用，不能只在 Prompt 里写“参考风格”。如果工具不支持至少一张身份图加一张风格图，不得声称能够稳定还原本风格；先说明限制，再等待用户决定是否接受低一致性测试。

## 形体硬约束

正面母图使用明显玩偶化比例：

- 总身高控制在约 2.6～3.3 个头高；超过 3.4 个头高直接失败。
- 头部连同主要发型体块必须明显大于肩宽，肩膀窄而圆。
- 脖子极短或基本隐藏，禁止成年人物的长颈连接。
- 躯干短、腰线弱化，禁止收腰、胸腰胯曲线和成人时装模特体态。
- 腿部短而稳定，不得依靠长腿、阔腿裤或厚底鞋把身体拉回成人比例。
- 手部使用简洁、略圆的角色手型；鞋子概括成清楚的圆角体块。
- 正面母图采用接近正面的中性站姿，重心稳定；禁止模特式侧身、扭腰、抬胯和扶衣襟摆拍。

长发可以保留为身份锚点，但必须压缩成 3～7 个清楚的大型发块和外轮廓弧面。禁止大量独立发丝、连续光泽带、写实卷发层次和头发覆盖半个身体后仍按真人发型渲染。

## 五官硬约束

- 脸型横向圆润、幼态、鼻部高度简化，腮红是清楚的角色元素。
- `minimal-face` 与 `accessory-led` 使用豆点眼、短线眼或高度概括眼睛。
- `expressive-eye` 允许半睁或较大的彩色眼睛，使用有限虹膜色层、一个主要阴影和少量高光；允许几根短而图形化的睫毛，但仍然是玩偶脸，不是通用日系动漫美少女脸。
- `round-open-eye` 使用清楚的圆形或椭圆睁眼、白眼球、单色虹膜和极少高光，优先承担基础人物的正式眼型锚点。
- 闭眼弧线、笑眼和其他眼睛变化可以用于表情、动作或贴纸；若角色尚无正式眼型，它们不能单独作为 `base-character` 的眼睛真源。
- 禁止美容化眼线、成排纤长睫毛、精细妆容、多层玻璃虹膜、鼻尖高光、唇妆、写实牙齿和商业头像式露齿笑。短而清楚的图形化睫毛不属于失败。
- 嘴型小而克制，可以是短线、小弧线或极小开口；表情服务于角色气质，不服务于“更漂亮”。
- 身份识别优先依靠发型剪影、脸型方向、眉眼气质、长期眼镜、痣、耳饰和招牌符号，不通过增加真人面部细节实现。

## 线条硬约束

- 外轮廓使用深棕或暖黑粗线，视觉重量约为主要内部线的 1.7～2.5 倍。
- 线条圆润、有自然粗细变化和轻微手绘弹性，但边缘保持清楚。
- 内部线条只用于必要结构；不逐条描绘发丝、拉链齿、口袋缝线、鞋底纹路和所有衣褶。
- 头发、脸、服装、手脚和配饰必须使用同一套线条语言。
- 细黑动漫线、局部无轮廓半厚涂、矢量般均匀描边和精修时装线稿均为失败。

## 上色硬约束

- 以清楚平涂为主体。每个主要色块最多使用基础色、一层浅阴影和一处克制高光。
- 阴影使用可读的柔边或简化色块，不使用全局气枪渐变塑造写实体积。
- 皮肤不做鼻尖高光、唇部光泽、浓重眼影和美容修图质感。
- 头发只在大型发块上放少量简化高光，不使用多层丝绸光泽和逐缕明暗。
- 配色通常由一个主色、1～2 个辅助色和一个强调色组成；大面积纯黑需被较明亮角色色平衡。
- 正式人物背景必须是纯白或几乎不可见的单一浅色；禁止米灰渐变、暗角、柔光光晕、地面投影和海报氛围。

## 服装与角色化

本风格不是照片穿搭复刻。服装需要转为清楚、圆润、可从侧面和背面成立的角色体块。

1. 保留已确认的服装身份，例如“短外套＋宽松长裤”，不保留所有现实结构细节。
2. 拉链、工装口袋、鞋底和衣褶压缩为少数识别符号；一处结构不重复画所有缝线。
3. 根据用户用途设计身份主色和 1～2 个主要招牌系统；一个系统可以由相互关联的服装、配饰、道具或特效组成，但不得堆砌无关物件。
4. 长期耳饰、眼镜或发夹可以保留，但必须简化成缩小后仍清楚的符号。
5. 参考图库中的帽子字母、文字、围巾、眼镜、背包、具体鞋型、配色和性别表达都属于示例人物，禁止复制。

### 低情境正装照

单张证件照、简历照或正装照只提供身份证据：

- 保留脸型方向、发型、眉眼气质、长期眼镜和可读身份特征。
- 正装、白背景、影棚光和证件照姿势默认不是长期角色设定。
- 有用户用途时据此提出角色化服装；没有背景资料时采用简单分层服装、无职业道具的中性方案。
- 正装是否代表长期职业身份会改变结果时，Skill 先给首选判断，只让用户纠正这一事实，不让用户选择专业绘画参数。

## 呈现方式

### 正面母图

- 单人完整全身，接近正面，姿势稳定。
- 纯白背景，无文字、无场景、无渐变、无地面阴影。
- 人物周围保留均匀空白，优先检查剪影和结构，不制作时尚海报。

### 三视图

1. 正面母图先独立生成、通过 QA 并由用户正式确认。
2. 以确认正面图作为人物、服装、比例和配色真源，分别生成侧面和背面。
3. 校验发型前后结构、配饰方向、服装开合、袖口、裤型、鞋型和身份色。
4. 最后组合成横向正面／侧面／背面设定稿，三个人物等高、同基线、间距一致、纯白背景。

未经确认的三联图不能替代正面人物确认。

## Prompt 风格段

本段只用于没有更具体内部 Profile 的软萌潮玩路线。`minimal-face` 必须改用其专属生产 Prompt 模板。

```text
目标是软萌潮玩Q版二维角色设定，不是精致日系动漫立绘、时尚头像或照片穿搭Q版化。采用 structural-redraw 从空白画布重构人物。风格优先于美化：总身高约2.6～3.3个头高，大头宽于窄肩，短颈、短躯干、弱腰线、短而稳定的腿和圆角手脚；禁止成人收腰、长腿与模特姿态。使用深棕或暖黑粗外轮廓，外轮廓约为内部线1.7～2.5倍，内部细节高度概括。脸部横向圆润、幼态、有清楚腮红和高度简化鼻部；根据本人身份选择豆点眼、有限层次半睁眼或圆形单色睁眼，允许少量短而图形化的睫毛，但禁止美容化眼线、成排纤长睫毛、多层玻璃虹膜、精细妆容、写实牙齿和商业式露齿笑。基础人物必须记录可复用的正式眼型；闭眼只作为后续表情，除非正式眼型已另有锚点。长发压缩成3～7个大型圆润发块，禁止逐缕发丝和多层丝绸光泽。上色以平涂为主，每个主要色块最多一层浅阴影和一处克制高光，禁止全局气枪渐变和半厚涂。把本人服装重构成圆润、简化、可扩展三视图的角色体块；允许具有角色意义的服装、道具和特效系统，但不逐条描绘无意义的拉链、口袋、鞋底和衣褶。纯白背景，无暗角、光晕、地面投影、场景和文字。不得复制风格参考人物的帽子、眼镜、围巾、背包、文字、具体服装、配色或性别表达。
```

## 生成后硬门

出现以下任一项直接判为失败，不展示成合格候选：

| 类别 | 失败条件 |
|---|---|
| 风格类别 | 第一眼是普通日系动漫Q版、精致美少女立绘、时尚人物海报或3D公仔 |
| 比例 | 超过约3.4头身；长颈、长腿、明显收腰或成人胸腰胯成立 |
| 五官 | 美容化眼线、成排纤长睫毛、多层玻璃虹膜、写实鼻唇、牙齿主导笑容、精细美容光泽；基础人物只有闭眼且没有正式眼型锚点属于任务失败，不属于风格失败 |
| 头发 | 大量独立发丝、连续高光带、写实卷发或半厚涂发丝层次 |
| 线条 | 外轮廓细且均匀、内部细节过密、头发与身体使用不同媒介 |
| 上色 | 大面积气枪渐变、皮肤精修、写实体积光、塑料或丝绸质感 |
| 服装 | 现实穿搭原样复刻，拉链、口袋、鞋底和衣褶细节没有角色化压缩 |
| 呈现 | 米灰渐变、暗角、光晕、地面投影、模特侧身或海报式构图 |
| 参考污染 | 复制任一示例人物的帽子、眼镜、文字、服装、背包、配色或性别表达 |

通过硬门后，再检查：

- 身份锚点是否足以认出本人。
- 主参考的比例、线条、脸部简化、体块和二维渲染是否真实出现。
- 服装和主要招牌系统是否形成长期可复用剪影，角色细节是否彼此相关而非随机堆砌。
- 是否具备继续制作侧面和背面的清楚结构。

QA 必须与主风格参考图并排查看。只看候选图本身不得判断“风格通过”。
