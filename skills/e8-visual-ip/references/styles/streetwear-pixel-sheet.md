# 街头像素角色设定风

## 目标

把真实人物重新设计成可长期复用的暗色街头像素角色：统一方形像素网格、有限色板、离散明暗色阶、青年 Q 版比例、宽松街头服装和正侧背角色设定结构。

这不是高分辨率插画套马赛克滤镜。转换使用 `structural-redraw`，必须从像素网格开始重新组织人物轮廓、脸部、头发像素簇、服装体块、色板和阴影块。

当前成熟度为 `limited-multi-reference`：两张独立参考重复证明了像素媒介、青年 Q 版比例、暗色街头轮廓、有限色板、单一强调色和三视图结构；浅色服装、明亮色板、长发、裙装、复杂道具和场景仍需单张验证。

默认相似度使用 `interpreted`。用户要求更像本人时最多推荐 `recognizable`；不得用写实五官、平滑曲线和现实身体比例换取相似。

## 参考路由

两张参考属于同一像素风格家族，但服装、发型与气质明显不同。目录展示 `accessory-purple`，用户据此选择后默认使用其正面裁图；切换到 `hair-accent-dark` 前必须展示差异并获得用户同意。

### `accessory-purple`

适用信号：

- 短发或紧凑发型。
- 耳机、帽子、眼镜等大型配饰承担身份识别。
- 需要较明确的服装主色。
- 气质偏年轻、亲和或略微内向。

第一次正面生成输入顺序：

1. `accessory_purple_front`：`primary style`。
2. 用户照片或正式人物：`identity`。
3. `accessory_purple_head`：可选 `secondary style`，只强化像素脸、头发和配饰边缘。

`accessory_purple_sheet` 只在正面确认后用于侧面、背面和三视图。

### `hair-accent-dark`

适用信号：

- 中短发、层次发型、挑染或发色强调承担身份识别。
- 整体希望更暗、更酷、更克制。
- 配饰较少，发型是主要记忆点。
- 中性气质或更成熟的青年表达。

第一次正面生成输入顺序：

1. `hair_accent_dark_front`：`primary style`。
2. 用户照片或正式人物：`identity`。
3. `hair_accent_dark_head`：可选 `secondary style`，只强化像素脸、发型层次和强调色像素簇。

`hair_accent_dark_sheet` 只在正面确认后用于侧面、背面和三视图。

## 八个正向风格锚点

### 1. 统一方形像素网格

- 所有轮廓、五官、头发、服装、手脚和配饰沿同一像素网格构建。
- 曲线通过阶梯状像素转折表达，不使用抗锯齿和平滑矢量边缘。
- 头部、身体和鞋子的像素块视觉尺寸一致，禁止局部超细像素与局部大马赛克混用。
- 最终缩放只能使用 nearest-neighbor；禁止双线性、双三次和模糊缩放。

### 2. 有限色板与离散明暗

- 全图通常使用约 16～28 个有意义颜色；不能出现数百种近似色。
- 每个材质通常使用基础色、1～2 层阴影和最多 1 层高光。
- 明暗通过边界清楚的像素色块表达，不使用渐变、柔光、透明阴影和模糊。
- 同一色板跨正面、侧面和背面保持一致。

### 3. 青年 Q 版比例

- 人物约 3.2～3.8 个头高，头部较大、肩膀窄、躯干短。
- 比软萌潮玩更修长，但不能达到真人、时装模特或普通成年动漫比例。
- 腰线弱化，手较小并图形化，重心稳定。

### 4. 大型头发像素簇

- 头发先形成清楚、可识别的大型剪影，再用少量像素簇表达层次。
- 深色头发使用近黑基础色和少量离散高光，不逐缕描绘平滑发丝。
- 发尾、刘海和挑染都通过阶梯状像素簇表达，不能成为柔顺矢量曲线。
- 长发属于当前未充分覆盖范围，首次只生成单张正面候选。

### 5. 高度概括的像素脸

- 眼睛、眉毛、鼻子和嘴只使用少量清楚像素。
- 不画复杂虹膜、睫毛、写实鼻唇和美容妆容。
- 眼镜只在用户长期佩戴时保留，并按本人镜框像素化；两张参考都有眼镜不代表所有人物必须戴眼镜。
- 面部识别主要来自发型、眼镜情况、脸型方向、配饰和整体气质。

### 6. 宽松街头服装体块

- 风格正式包含落肩、宽松躯干、蓬松袖子、短躯干和大块口袋结构。
- 连帽卫衣是示例内容，但其宽松街头形状功能必须迁移到夹克、衬衫、正装或其他服装身份。
- 服装褶皱只用少量暗色像素簇表达，不刻画缝线、纹理和真实布料细节。

### 7. 宽松裤腿和厚重鞋型

- 裤腿宽松，脚踝附近有少量堆积色块。
- 鞋子厚重、轮廓稳定、结构简化，帮助人物形成街头重心。
- 禁止贴腿裤、真人腿型、尖细鞋和密集鞋带纹理。

### 8. 暗色主体＋一个强调色系统

- 深灰、近黑和低明度中性色构成主体。
- 使用一个主要强调色系统，例如紫色服装、红色发束或用户身份色；强调色面积克制、位置稳定。
- 肤色、头发、服装、鞋和配饰使用有限色板协调，不平均铺开彩虹色。
- 用户没有明确强调色时，Skill 根据长期身份色或角色方案推荐一个，不复制示例紫色或红色。

## 像素簇与阴影规则

- 高光和阴影必须形成有方向、相互连接的像素簇，不随机散布单个噪点。
- 头发高光使用少量短块；服装阴影沿袖子、口袋、下摆和裤腿内侧组织。
- 避免 pillow shading：不能在每个物体中心放亮色、边缘均匀变暗。
- 避免抖动噪点、半透明像素和无规律色彩交错。
- 白色背景保持纯净，不添加阴影、场景、文字、网格辅助线和装饰。

## 示例人物与身份边界

不得默认复制：

- 黑框眼镜。
- 黑色短发或黑红挑染。
- 黑色耳机、银色耳饰。
- 紫色卫衣或全黑卫衣。
- 具体裤型、鞋型、性别和表情。

必须迁移的设计功能：

- 眼镜背后的面部像素框架；用户不戴眼镜时改用眉眼与发型保持重心。
- 耳机背后的大型招牌配饰系统；只有用户身份需要时才添加相应配饰。
- 卫衣背后的宽松街头轮廓；不是所有用户都必须穿卫衣。
- 紫色和红色背后的“暗色主体＋单一强调色”配色策略。
- 发型背后的大型像素簇与阶梯状外轮廓，而不是复制具体发型。

## 参考成熟度边界

以下情况已获得两张参考的重复证据，可以正常测试：

- 短发或中短发。
- 暗色街头服装。
- 单一强调色。
- 眼镜或少量大型配饰。
- 中性正面、标准侧面和背面。

以下情况仍需单张候选确认：

- 长发、浅色头发和大面积明亮发色。
- 浅色服装、裙装和正式礼服。
- 多个复杂道具、动态姿势和复杂场景。
- 明亮高饱和整体配色。

## 呈现与生成顺序

### 第一次生成

1. 从目录选择时使用注册表指定的默认主参考；只有用户同意切换后才使用另一套内部参考。
2. 只生成一张正面完整人物，不直接生成三联图。
3. 主风格正面裁图第一，身份图第二，头部裁图按需第三。
4. 检查像素网格、色板、比例、头发、脸、服装、下装和强调色八项锚点。
5. 用户确认正面人物后再扩展侧面与背面。

### 三视图

1. 已确认正面人物作为人物、色板、服装和像素尺度真源。
2. 对应完整参考图只控制标准侧面、背面和横向版式。
3. 分别生成侧面与背面，校验发型、眼镜、配饰、连帽结构、袖口、裤腿、鞋型和强调色位置。
4. 最后组合成等高、同基线、间距一致的横向三视图。

## 生成后硬门

出现以下任一项直接失败：

| 类别 | 失败条件 |
|---|---|
| 媒介 | 普通插画套马赛克、像素尺寸不统一、抗锯齿、平滑曲线、模糊边缘或双线性缩放 |
| 色板 | 渐变、透明阴影、柔光、数百种近似色、跨视角色板漂移或多个无主次强调色 |
| 像素簇 | 随机单点噪声、抖动杂点、pillow shading、高光阴影没有形成有方向的连贯色块 |
| 比例 | 真人、时装模特、普通成年动漫或短胖软萌公仔比例 |
| 头发 | 平滑发丝、像素尺度混乱、写实高光，或无依据复制黑短发／黑红挑染 |
| 脸部 | 复杂虹膜、写实鼻唇、美容妆感，或用户不戴眼镜却复制黑框眼镜 |
| 服装 | 失去落肩宽松街头体块，现实服装未重构，或直接复制紫色／黑色卫衣 |
| 下装鞋型 | 贴腿裤、真人腿型、尖细鞋、复杂鞋带纹理或脚踝缺少松弛结构 |
| 配色 | 不是暗色主体＋一个强调色系统，或直接复制示例紫色／红色 |
| 参考污染 | 复制耳机、耳饰、眼镜、发型、服装、性别和表情，且这些并非用户身份 |
| 呈现 | 背景非纯白，出现场景、文字、阴影；三视图不等高、不同基线或像素尺度不一致 |

通过硬门后，八项正向风格锚点必须逐项标记 `PASS`。任一核心锚点完全缺失，候选状态为 `rejected`，不得展示成可确认版本。
