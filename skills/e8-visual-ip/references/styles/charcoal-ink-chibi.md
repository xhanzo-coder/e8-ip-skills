# 黑灰墨线轻 Q 版

## 当前状态

本风格处于 `candidate`，只允许用户明确点名后的校准测试，不进入首次风格目录、不自动推荐、不声明任何稳定产物。只有真实人物样张通过、用户确认风格方向并完成覆盖测试后，才能升级为 `active`。

## 目标

把人物重构为暖白肤色、炭黑实心头发与服装、黑色墨线和中性灰腮红组成的低饱和轻 Q 角色。它不是普通黑白线稿，也不是彩色 Q 版简单去色。

优先级：

```text
黑灰实心块与极简墨线语法
→ 2.8～3.2 头身的轻 Q 结构
→ 可辨识的人物剪影与年龄气质
→ 用户指定服装
```

## 独立风格边界

- 本风格使用大面积炭黑头发、上衣、短裤或鞋块，允许灰色腮红和暖白肤色。
- 五官是大型黑色椭圆眼、点鼻和极小嘴，整体更可爱、更紧凑。
- 本风格以紧凑比例、炭黑实心块、暖白皮肤和圆形灰腮红构成完整语法，不能退化为普通黑白线稿或日系漫画人物。

## 单参考覆盖边界

当前唯一参考只证明：短发、黑色宽松短袖与短裤、正面／标准侧面／背面、黑灰白媒介和紧凑比例能够成立。它不能证明长发、浅色头发、复杂肤色映射、女性长发、不同年龄、眼镜、复杂服装、动作、表情或场景稳定。

参考图中的三视图不等于当前风格已经通过三视图验证。首次运行只能生成一张正面候选。

## 八个正向风格锚点

### 1. 紧凑轻 Q 比例

- 完整人物约 2.8～3.2 个头高。
- 头顶到下巴约占总身高 31%～36%。
- 下巴到上衣下摆约占 29%～34%，下摆到鞋底约占 33%～39%。
- 不是两头身幼儿贴纸，也不是四头身以上普通动漫人物。

### 2. 大头、窄肩与短肢

- 头部是最大形状，肩宽不得超过头宽约 95%。
- 颈部极短、躯干紧凑，手臂和小腿使用纤细简化结构。
- 手只保留少量圆角指形，鞋为小型扁平体块。
- 成年气质只能通过眉眼、嘴型和神态表达，不能通过拉长身体表达。

### 3. 黑色墨线层级

- 轮廓使用纯黑或近黑墨线。
- 外轮廓为中等线重，约为内部线的 1.3～1.7 倍。
- 线条清楚、连续、略带手绘弹性；不能细成精致动漫线稿，也不能粗成潮玩贴纸描边。

### 4. 无彩色阶

- 纯白或近白负责背景与鞋头等留白。
- 暖白负责皮肤和少量服装留白。
- 炭黑／近黑负责头发、眼睛、主要服装和鞋。
- 中性浅灰负责圆形腮红、点状鼻子或袜子。
- 禁止出现绿色、蓝色、棕色、粉色等饱和彩色。

### 5. 炭黑实心头发

- 头发以一个清楚的炭黑大型剪影为主，只允许极少近黑色阶或克制内部短线。
- 身份通过发际线、刘海关系、分缝、长度、发尾与外轮廓保持。
- 禁止高光带、逐缕发丝、半厚涂和写实光泽。

### 6. 极简面部语法

- 眼睛为大型纯黑或近黑椭圆，只有一到两个很小的白色高光。
- 眉毛为短而清楚的黑色弧线。
- 鼻子是浅灰小点，嘴是极小点、短线或小开口。
- 两侧大面积圆形浅灰腮红是核心风格锚点。
- 禁止玻璃虹膜、长睫毛、眼线、唇妆、牙齿和写实鼻梁。

### 7. 黑色大型服装块

- 服装压缩为少数大型炭黑或暖白块面，不逐条描绘衣褶和缝线。
- 参考中的黑色宽松短袖、短裤、灰袜和黑色低帮鞋作为 `reference-outfit` 选项；只有用户明确选择时才整体采用。
- 用户选择其他服装时，仍必须保持黑灰白块面关系。

### 8. 纯净角色设定呈现

- 正面母图为单人完整全身、纯白或近白背景；允许与参考一致的极轻中性灰边缘衰减，但不能形成可感知的聚光或暗角。
- 无文字、场景、地面线、明显投影、强暗角和彩色氛围光。
- 三视图只有在正面人物确认后才能生成，并必须等高、同基线。

## 身份映射

默认相似度为 `interpreted`。只保留 2～5 个缩小后可读的身份锚点：脸型方向、发际线、发型剪影、眉眼气质、眼镜／痣／耳饰等长期符号、年龄与稳定神态。

真实发色和服装颜色会被无彩色阶转译，不能作为相似度证据。若用户要求 `recognizable`，必须单独执行脸部比例、发际线额头、眼眉关系、中下脸关系、年龄神态五项身份检查；任一失败即拒绝。

## 参考隔离

默认禁止复制参考人物的：

- 短碎发、头顶翘发和具体刘海；
- 参考人物的脸、性别和表情；
- 黑色短袖、短裤、袜子和鞋的完整组合，除非用户明确选择 `reference-outfit`；
- 正侧背中的具体身体细节。

## 生成后硬门

出现任一项即 `rejected`：

- 第一眼属于普通黑白线稿、日系动漫、软萌潮玩、全彩 Q 版或写实人物。
- 超过 3.2 头身、肩宽超过头宽约 95%，或退化为两头身幼儿贴纸。
- 缺少炭黑实心发块、黑色椭圆眼或圆形灰色腮红。
- 引入明显饱和彩色、棕色头发、彩色衣服或复杂肤色渲染。
- 头发出现连续高光、写实发丝、渐变塑料光泽或半厚涂。
- 线条过粗、过细，或头发、脸和服装不属于同一墨线语言。
- 出现明显投影、渐变背景、暗角、纸张纹理、场景或地面线。
- 未获授权时复制参考人物的短碎发和完整服装组合。

## 候选升级条件

1. 一张真实人物正面校准样张通过身份、风格与任务三层 QA，并由用户明确确认。
2. 再完成至少两种不同身份结构的正面测试。
3. 完成一组由已确认正面母图扩展出的侧面和背面测试。
4. 根据真实结果把已通过产物移入 `supported_outputs`；未测试产物继续保留在 `unverified_outputs`。
