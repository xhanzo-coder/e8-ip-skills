# 极简黑白漫画设定风

## 目标

把真实人物重新设计成纯黑白漫画角色设定稿。正式结果必须同时满足：

1. 仍能辨认出目标人物，而不是只看出发型或服装类别。
2. 使用纯黑墨线、实心黑块和白色负空间完成，不是照片去色或普通动漫线稿。
3. 具备可继续扩展侧面、背面、表情和动作的稳定角色结构。

本风格采用 `structural-redraw`。身份与风格不是互相覆盖的总优先级，而是分层负责：

```text
身份参考：头部几何、脸龄、发际线、眉眼、鼻口下颌和人物气质
风格参考：黑白媒介、线条层级、抽象方式、身体比例、服装体块和画布呈现
```

不得用“风格优先”删除人物辨识度，也不得用写实五官、成人真人比例或照片描线破坏风格。个人照片创建默认使用 `recognizable`；只有用户明确要求抽象化、符号化或“只保留气质”时才使用 `interpreted`。`close` 可以增强身份几何，但仍不能变成写实肖像。

## 单张候选原则

用户确认方案后，每轮只生成一张正面全身基础人物候选。这张图必须同时承担正式身份和正式风格确认，不默认生成“头像一张＋全身一张”，也不自动连烧第二版。

首张身份层失败时，先停止并说明失败的身份锚点。只有用户明确同意专门校准脸部时，才可额外生成头部校准图；校准图只是修复工具，不能替代最终正面全身母图。

## 参考成熟度

当前只有一张独立正式参考，成熟度为 `single-reference`。`front_character` 和 `face_hair_detail` 是同一原图的精确裁图，不是新增独立样本。

- 已确认：纯黑白媒介、黑白面积关系、两级线条、约四头身结构、宽松服装和设定稿呈现。
- 尚未充分验证：不同年龄和脸型的可识别身份、浅色头发、长发、复杂配饰、多人、复杂动作和场景。
- 当前参考中的少年脸不能成为所有用户的固定脸模版；成熟人物不得被强制改成同一种少年脸。
- 超出覆盖范围时只生成单张候选并明确边界，不批量推断。

## 参考路由

### `recognizable` 或 `close`：身份优先

创建真实人物的正面基础人物时，输入顺序固定为：

1. 从全部身份照片中选择一张最清晰、最接近正面、脸部无遮挡的主身份图：`primary identity`。
2. `reference_assets.front_character`：`primary style`，只控制黑白媒介、抽象方式、身体比例、服装体块和线条。
3. 必要时加入一张确实补充侧脸、发际线或招牌特征的身份图：`secondary identity`。

不得为了“多参考更稳”把全部照片都传入；主身份图必须承担明确的脸部真源。`face_hair_detail` 在身份优先路线中只用于生成前分析和生成后 QA，禁止传入图片工具，因为它会重复强化示例人物的少年脸、圆眼和具体发型。

### `interpreted`：风格优先

用户明确接受符号化身份时，输入顺序为：

1. `reference_assets.front_character`：`primary style`。
2. 一张主身份图：`identity`。
3. `reference_assets.face_hair_detail`：可选 `secondary style`，只加强脸部线条和头发概括方式。

`interpreted` 结果不得被称为“别人能认出本人”。

### 头像、脸部修复与三视图

- 头像或脸部修复：优先使用已经确认的正面全身人物作为身份真源；没有正式人物时仍遵循对应相似度的参考路由。
- 侧面、背面和三视图：以用户已确认正面人物为人物、服装与黑白面积真源，`full_sheet` 只控制视角组织和版式。
- 首次正面生成不得把完整三视图 `reference.png` 传入图片工具。
- 负面样本只用于 QA，绝对禁止传入生成工具。

## 五项身份指纹

`recognizable` 和 `close` 的正面候选必须逐项检查以下身份指纹。发型、眼镜、服装和道具不能代替脸部身份通过。

### `identity_anchor_1_face_proportion`

保留脸部宽高方向、颧颊体量和下颌收放关系。圆脸、长窄脸、宽下颌、尖下颌不能统一画成同一种圆少年脸。

### `identity_anchor_2_hairline_forehead`

保留发际线高度、额头暴露、分缝、前额发束方向和两侧长度。发色在黑白中转译，但不得因此改变真实发型类别。

### `identity_anchor_3_eye_brow_relation`

保留眼睛大小趋势、横纵比例、间距、倾斜、眼睑重量，以及眉毛粗细、角度和眉眼距离。眼睛仍是简洁黑白图形，但不能把所有人都画成相同的大圆高光眼。

### `identity_anchor_4_mid_lower_face`

用极简线或负空间保留鼻部长度／宽度方向、鼻口距离、嘴型、唇线趋势和下巴关系。可以高度简化，不能完全删除所有中下脸差异。

### `identity_anchor_5_age_mood`

保留人物的大致年龄阶段、性别表达和稳定神态。成熟或老年人物可以使用克制的眼睑、眉眼、面颊或下颌线索表达年龄；禁止写实皱纹，也禁止统一幼化成少年。

五项必须在 `analysis.md` 中先写出目标，在 `qa.md` 中逐项记录可见证据。`recognizable` 或 `close` 任一身份锚点失败时，身份层为 `FAIL`，候选不得成为 `approved_candidate`。

## 八个风格锚点

### `anchor_1_identity_adaptive_eyes`

- 使用纯黑白、边界清楚、内部层级克制的图形眼。
- 眼睛可以比真人略大以适配 Q 版，但大小、间距、倾斜和眼睑重量必须服从身份指纹。
- 允许圆形、椭圆或较窄的简化眼型；不再强制所有人物使用同一个大圆眼框架。
- 禁止彩色玻璃虹膜、美容眼线、密集睫毛和写实眼球建模。

### `anchor_2_hair_silhouette`

- 把用户真实发型转译为清楚的大型黑白剪影，保留发际线和前额方向。
- 深色头发可用连续实心黑块；浅色头发使用白色负空间、黑色轮廓和少量结构线。
- 浅发人物不得为了满足黑块构图被凭空添加黑色发根、黑色后脑或不属于本人的深色发束。
- 不复制示例人物的短黑发和遮额刘海。

### `anchor_3_stylized_structure`

- 人物约 3.7～4.2 个头高，头部约占总高度四分之一。
- 肩部相对简化，脖子较短，腰线弱化；身体仍是风格化角色，不是成人时装插画。
- 体态可以保留人物年龄与气质，不能强制少年身份，也不能退化成短胖软萌公仔。

### `anchor_4_oversized_garment`

- 把衬衫、夹克、卫衣或正装转译为落肩、宽松、圆润、少衣褶的角色体块。
- 可保留长期服装身份的领型、开合和招牌符号，但不得复制现实肩线和所有结构细节。
- 服装只能辅助识别，不能单独证明人物身份。

### `anchor_5_relaxed_lower_body`

- 裤腿宽松，脚踝有少量堆积或折线，鞋头圆润简化。
- 禁止贴腿裤、尖长成人鞋和密集鞋底纹理。

### `anchor_6_line_hierarchy`

- 外轮廓视觉重量约为主要内部线的 1.8～2.2 倍。
- 头发、脸、衣服、手脚和道具使用同一墨线语言。
- 内部线只表达身份与结构所需信息；禁止平均细线、密集衣褶和商务矢量线稿。

### `anchor_7_black_mass`

- 深发人物通常以头发作为最大连续黑块。
- 浅发人物允许头发主要留白，主黑块可由眼睛、领带、服装局部或其他真实身份元素承担；不得发明不存在的黑色头发区域。
- 黑块之间保持白色间隙，不能用无意义黑门襟或整件黑衣抢夺重心。

### `anchor_8_identity_aligned_mood`

- 表情简洁而稳定，保留人物的亲和、克制、自信、严肃或松弛倾向。
- 正面母图身体稳定但不机械，允许轻微不对称。
- 禁止把所有人统一成安静少年、商务证件照或模特摆拍。

## 黑白媒介硬约束

- 最终成品只使用纯黑、纯白和边缘抗锯齿产生的不可感知过渡。
- 禁止主动灰色区域、彩色、网点、排线、渐变、投影、纸纹、铅笔颗粒、水墨晕染和半厚涂。
- 背景纯白，无文字、场景、边框、装饰和地面阴影。
- 白色是正式负空间，不是等待上色的空白。

## 示例人物的可迁移边界

不得复制：具体短黑发、圆框眼镜、白色连帽衫、宽松长裤、具体鞋型、咖啡杯、少年身份、脸型与动作。

只允许迁移：纯黑白媒介、两级线条、约四头身的设定稿比例、少衣褶的宽松服装、黑白面积组织和视角版式。眼睛与脸部只学习“图形化与克制”，不能复制具体大小和比例。

## Prompt 生产段

```text
生成一张可被正式确认的极简黑白漫画正面全身人物候选，每轮只生成一张。采用 structural-redraw：身份参考负责头部几何与人物辨识，风格参考负责纯黑白媒介、线条层级、身体比例、服装体块和白底设定稿呈现。默认 likeness=recognizable。

先保留五项身份指纹：脸部宽高与下颌、发际线与额头、眼眉大小/间距/倾斜、鼻口下巴关系、年龄与稳定神态。眼睛是简洁黑白图形，可以略大但必须依据本人变化，禁止统一大圆眼。鼻口可以极简但不能删除全部中下脸差异。成熟人物保持成熟身份，不写实画皱纹，也不幼化成少年。

身体约3.7～4.2头高，风格化窄肩、短颈、弱腰线；服装转译为落肩、宽松、圆润、少衣褶体块；裤腿宽松、脚踝少量堆积、鞋型圆润。外轮廓约为内部线1.8～2.2倍。深发使用主黑发块；浅发使用白色负空间与黑轮廓，不添加虚构黑发根。纯黑纯白，禁止灰阶、网点、排线、渐变、阴影、纸纹、场景和文字。

不得复制风格示例的脸、发型、眼镜、连帽衫、咖啡杯、少年身份和动作。发型或服装符号成立不能单独算人物相似；身份层与风格层都通过才是正式候选。
```

## 生成后硬门

出现以下任一项直接失败：

| 类别 | 失败条件 |
|---|---|
| 身份 | `recognizable/close` 任一五项身份指纹失败；只靠发型、眼镜、服装或道具才能猜出人物 |
| 眼睛 | 所有人都被画成同一种大圆高光眼；眼睛大小、间距、倾斜与本人明显相反 |
| 脸龄 | 成熟人物被统一幼化；长窄脸被压成圆少年脸；下颌和中下脸方向丢失 |
| 头发 | 发际线、额头暴露或主发束方向错误；浅发被添加不存在的黑发根或黑色后脑 |
| 比例 | 低于3.7或高于4.2头身；退化成短胖公仔或成年写实比例 |
| 服装 | 现实结构原样复刻，或复制参考连帽衫；服装符号被当作身份通过证据 |
| 媒介 | 主动灰阶、彩色、网点、排线、渐变、投影、纸纹或半厚涂 |
| 线条 | 外内线无层级、内部线过密、脸与身体使用不同媒介 |
| 呈现 | 非纯白背景、场景、文字、边框、地面阴影、裁脚或多人 |
| 参考污染 | 复制示例人物的脸、具体眼型、发型、眼镜、服装、道具、少年身份或动作 |

通过五项身份指纹、八项风格锚点和任务层后，才可标记 `approved_candidate`。运行契约证明流程完整，但不能替代真实视觉判断或用户正式确认。
