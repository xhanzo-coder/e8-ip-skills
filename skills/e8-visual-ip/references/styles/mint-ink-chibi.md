# 薄荷墨线轻 Q 版

## 当前状态

本风格处于 `candidate`，只允许显式校准测试，不进入首次风格目录、不自动推荐、不声明任何稳定产物。只有真实人物校准样张通过、用户确认风格方向并完成后续覆盖测试后，才能升级为 `active`。

## 目标

把人物重构为暖白留白、森林绿墨线和薄荷强调色组成的三色轻 Q 角色。它不是普通黑白线稿加绿色，也不是软萌潮玩风换色。

优先级：

```text
三色墨线与负空间语法
→ 2.4～2.8 头身的轻 Q 结构
→ 可辨识的人物剪影与年龄气质
→ 服装和临时装饰
```

## 单参考覆盖边界

当前唯一参考只证明：短发、简单宽松服装、正面／标准侧面／背面、浅色大面积留白和三色媒介能够成立。它不能证明长发、深色实心头发、复杂肤色映射、男性角色、不同年龄、眼镜、复杂服装、动作、表情或场景稳定。

所有首次运行只能生成一张正面候选。不得因为参考图本身包含三视图，就直接承诺或生成正式三视图。

## 八个正向风格锚点

### 1. 紧凑轻 Q 比例

- 完整人物约 2.4～2.8 个头高。
- 头部宽于肩膀，颈部短，躯干短而稳定。
- 不是两头身幼儿贴纸，也不是四头身以上普通动漫人物。
- 头顶到下巴约占总身高 36%～42%；下巴到上衣下摆约占 27%～32%；下摆到鞋底约占 30%～35%。
- 肩宽不得超过头宽约 75%。即使用户要求年轻成年气质，也不能通过拉长躯干和腿来表达。

### 2. 大头与纤细肢体的对比

- 头部是最大形状，肩窄。
- 手臂和小腿使用纤细、近直线的简化结构。
- 手只保留少量圆角指形，鞋是小型扁平体块。

### 3. 森林绿墨线层级

- 所有轮廓使用近黑森林绿，不使用纯黑。
- 外轮廓为中等线重，约为内部线的 1.3～1.7 倍。
- 线条略有手绘弹性，但必须清楚、连续、克制。

### 4. 三色限制

- 暖白／奶油白负责大面积留白。
- 深森林绿负责轮廓、眼睛与少量实心结构。
- 浅薄荷绿负责腮红、鼻尖或一个小型强调区域。
- 不增加肤色、发色、衣服彩色或第四种装饰色。

### 5. 负空间头发与服装

- 头发主体保持暖白，不填成黑色、棕色或渐变色。
- 发型身份通过外轮廓、分缝、刘海、发尾和少量内部短线表达。
- 服装主体同样以留白为主，只在领口、袖口、裤装、鞋或一个招牌位置使用深绿。

### 6. 极简面部语法

- 眼睛为大型深森林绿椭圆或圆角椭圆，只有极少高光。
- 眉毛是短而清楚的图形弧线。
- 鼻子是薄荷小点，嘴是极小点、短线或小开口。
- 两侧圆形薄荷腮红是核心风格锚点。
- 禁止玻璃虹膜、长睫毛、眼线、唇妆、牙齿和写实鼻梁。

### 7. 大型服装块面

- 上衣、外套或裙装必须压缩为一到两个大型几何块面。
- 袖口、领口、下摆最多保留少量深绿结构。
- 禁止复制参考人物的宽松短袖、短裤与帆布鞋组合。

### 8. 纯净角色设定呈现

- 正面母图为单人完整全身、纯暖白或纯白背景。
- 无文字、无场景、无投影、无渐变、无纸张噪点。
- 三视图只有在正面人物确认后才能生成，并必须等高、同基线。

## 身份映射

默认相似度为 `interpreted`。只保留 2～5 个缩小后可读的身份锚点：脸型方向、发际线与刘海关系、发型剪影、眉眼气质、眼镜／痣／耳饰等长期符号、年龄与稳定神态。

成年、冷静、专业或成熟等气质只能通过眉毛角度、眼睛开合、嘴型和站姿表达；不得通过增加头身、肩宽、颈长、躯干或腿长表达。

真实发色、肤色和服装颜色会被三色系统转译，不能作为相似度证据。若用户要求 `recognizable`，必须单独执行脸部比例、发际线额头、眼眉关系、中下脸关系、年龄神态五项身份检查；任一失败即拒绝。

## 参考隔离

参考人物只提供比例、三色体系、线条、负空间、面部语法和设定稿结构。禁止迁移：

- 波波头和具体刘海；
- 黑色发夹；
- 宽松短袖、短裤、袜子和帆布鞋；
- 参考人物的性别、脸型和表情；
- 正侧背的具体身体细节。

## 生成后硬门

出现任一项即 `rejected`：

- 第一眼属于普通黑白动漫、软萌潮玩换色、全彩 Q 版或写实人物。
- 超过 2.8 头身或退化为两头身幼儿贴纸。
- 肩宽超过头宽约 75%，或躯干、裤腿明显接近普通成年动漫比例。
- 使用纯黑、肤色、棕色头发、彩色衣服或超过三色。
- 头发出现深色实心填充、连续高光、渐变或写实发丝。
- 缺少圆形薄荷腮红、大型深绿椭圆眼或负空间结构。
- 线条过粗像潮玩、过细像精致动漫线稿，或内外线没有层级。
- 出现阴影、体积光、纸张纹理、渐变、投影或场景。
- 复制参考人物的短波波头、发夹和整套服装。
