# 局部工作流

用户可以从任意合理阶段开始，不强制每次执行完整流程。

## 只分析人物

输出稳定特征、建议保留、建议重构、默认舍弃和需要核对；不生成方向和图片。

## 只给人物方向

完成分析并给 2–3 个结构不同的方向；不调用图片工具。

## 只生成候选

前提是人物方向、相似程度、风格和配色已经明确，并且用户已明确授权按该方案生成。创建基础人物时首次只生成一张正面候选；不得把“帮我创建”理解为已授权生图。

## 只新增风格

要求当前对话有正式人物图，或能从共享角色包解析人物。人物不变；先确认风格转换方案，再生成一张校准样张，确认方向并通过 QA 后才能正式确认和保存。

## 只生成衍生图

要求人物基准和风格均已正式确认。请求只改变动作、表情、头像裁切、允许的换装或视角时，用一句话声明保持项和变化项后直接组装 Prompt、生成并执行三层 QA，不重新分析本人照片；改变核心身份结构时转为重设计流程。

## 只写 Prompt

输出并保存完整 Prompt 与参考图用途，不调用图片工具。

## 只检查一致性

逐项比较头型、脸龄、五官语法、发型、比例、招牌符号、身份色、线条和媒介，输出：

- 一致。
- 轻微漂移，可局部修复。
- 核心漂移，需要重做。

## 只修复

明确待修复图、身份基准、风格基准、本轮只改项和不可变项。连续两次修复仍失败时停止局部编辑，建议重生成该图。
