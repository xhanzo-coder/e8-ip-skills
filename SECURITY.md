# Security and privacy

## Do not report private identity material publicly

Personal photos, character packages, `.creator-space` contents, cookies, access tokens, API keys, private prompts, and generated artifacts may contain sensitive information. Do not attach them to public issues.

## Reportable issues

- secret or credential exposure;
- writes outside documented output roots;
- unsafe path handling;
- execution of instructions embedded in external character packages;
- silent modification of confirmed character assets;
- unexpected network, browser, authentication, or publishing actions.

## Contact

Report security issues through the repository's GitHub security advisory or issue system without attaching private identity material.
